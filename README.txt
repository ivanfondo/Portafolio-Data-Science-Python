El ejercicio planteado consiste en construir una regresión lineal múltiple empleando el dataset Life Expectancy.

La variable objetivo (Y) en este escenario son los años de vida. Mediante la regresión lineal se trata de determinar
que variables independientes (X) son determinantes para ver como aumenta o disminuye la esperanza de vida.

El flujo de trabajo empleado es:
	1. EDA
	2. Encoding Variables Categóricas
	3. Selección de features (Variables)
	4. Entrenar el modelo y evaluar métricas
	5. Evaluar residuos.

Se realiza la regresión dos veces, una para el caso general seleccionando todos los datos y luego para los datos
del año 2015.
